Comment cela fonctionne

Les nouveaux membres du staff enregistrés sur cette page sont sauvegardés localement dans le navigateur via localStorage. Ils sont ensuite fusionnés avec les profils de base contenus dans users.json.
Limite du prototype

Les inscriptions ne sont pas partagées entre plusieurs ordinateurs ou navigateurs. Pour une gestion centralisée réelle, il faudra ensuite connecter l’application à une base de données en ligne.
